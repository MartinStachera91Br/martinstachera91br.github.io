# martinstachera91br.github.io

Source of my portfolio site: **https://martinstachera91br.github.io**

Growth marketer specialized in paid media and media buying (Google Ads, Meta Ads, LinkedIn Ads). The site has two parts:

- **Marketing results**: paid media case studies with the numbers that matter (CPL, CAC, ROAS, revenue, LTV).
- **AI & data projects**: the systems I build to measure, automate and scale marketing work.

## How it's built

- One static page: `index.html` with inline CSS, no framework and no build step.
- Light and dark mode follow the visitor's system setting.
- Hosted on GitHub Pages from the `main` branch.
- `og-image.png` is the preview image shown when the link is shared on LinkedIn, Slack or WhatsApp.
