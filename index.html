Content Data Enrichment PipelineGenna AICode on GitHub ↗

2x follower-growth speed

Viral hits went from 1 to 4.2 per 30 videos

A Python pipeline that sends every Instagram post through GPT-4o and Gemini Flash, plus Whisper for transcripts, to extract 62 creative features per post. Machine learning then shows which features drive performance, and those findings guide what gets produced next.

How it works
  • 484 posts processed. Features cover visuals, hook, people, audio, narrative and copy, plus 15 format-specific ones proposed by AI and curated by me.
  • Sources joined by Unix timestamp with a 97.2% match rate.
  • scikit-learn modeling against 5 performance metrics, with AI output evaluation and API cost tracking.

Self-Editing Short-Form Videos with ClaudeCapCut

Raw talking-head clip to edited vertical draft, unattended

CapCut has no API, so this edits projects by writing CapCut's own JSON draft files. It transcribes the clip with word-level timing, finds silences, cuts silences and repeated takes on word boundaries, and builds a vertical 1080×1920 draft for short-form video.

How it works
  • Whisper for word timings, ffmpeg for silence detection.
  • Animated hook overlays rendered in Remotion as transparent video and placed on the timeline.
  • Processed a batch of 4 videos with no one at the keyboard. I only refine the final cut.
  • Built on an existing CapCut bridge kit from another developer. My part: adapting it to run on Windows from Claude's sandbox, the cutting rules, the batch workflow and the Remotion overlays.
  • Python
  • Whisper
  • ffmpeg
  • Remotion
